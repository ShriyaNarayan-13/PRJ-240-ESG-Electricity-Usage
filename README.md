# PRJ-240 ESG Electricity Usage

## Development of Systems for effective Environment, Social and Governance (ESG) Invention in Higher Education

**Domain:** Environment  
**Sub-domain:** Electricity Usage

### Project Overview
A simple web-based dashboard for recording and viewing electricity consumption in selected college locations.

### Locations
- Academic Block
- Library
- Hostel

### Main Features
- Add electricity usage records
- View total electricity consumption
- Compare usage by location
- Identify high-usage records
- Display a simple usage chart
- Use sample CSV data for demonstration

### Technology
- HTML
- CSS
- JavaScript
- Chart.js
- CSV sample data

### Scope
This first version uses manual/sample electricity readings. It does not require IoT hardware or AI prediction.

## How to Run
Open `index.html` in a web browser.

For the Review-1 demonstration, the sample data is already included in the dashboard.
